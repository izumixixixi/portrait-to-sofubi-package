# Flow 1 Material Variant — Pink Blank

Use this variant only after the user selects **粉色素体**.

## Input role

- `Image 1 = accepted person cutout; sole reference for identity, pose, action, silhouette, clothing masses, and character-specific content.`
- `Image 2 = assets/flow-1-material-reference.png; reference only for pink soft-vinyl color, oily gloss, optical depth, specular highlights, and studio lighting.`

Never copy Image 2's character, face, anatomy, clothing, pose, proportions, silhouette, or framing.

## Color and finish

Make the complete toy an unpainted monochrome **bubblegum-pink sofubi blank**. Face, hair, skin, clothing, accessories, hands, legs, and shoes must all use the same pink vinyl. Do not add painted eyes, skin tone, clothing colors, decals, or secondary colors.

Match the reference's creamy, luminous, oil-polished soft-vinyl finish: bright rounded white-core highlights, smooth curved highlight ribbons, soft feathered reflections, full-bodied pink midtones, and deeper saturated pink turning shadows. The surface must remain clean and dry; oily describes optical luster, not literal liquid.

Reject pale washed-out pink, magenta, peach, lavender, matte pastel, satin plastic, powder, chalk, wax, dry rubber, frosted material, flat diffuse-only shading, foggy bloom, weak highlights, or overexposure.

## Material-only correction

If a correct sculpt looks dull, edit only its finish and lighting response. Preserve geometry, pose, proportions, face, silhouette, exact color family, framing, and background.
